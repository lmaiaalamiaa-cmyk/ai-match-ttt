# AI MATCH PRO - مشروع Android جديد

## ما الذي يعمل في هذه النسخة؟
- واجهة عربية Android مبنية بـ Kotlin وJetpack Compose.
- إدخال مفتاح Highlightly من داخل التطبيق وحفظه محلياً على الهاتف.
- جلب مباريات يوم محدد من Football API.
- عرض الدوري والفريقين والنتيجة والحالة والدقيقة إن توفرت.
- تصفية المباريات المباشرة بحسب حالة المباراة.
- اختيار اليوم السابق/التالي والتحديث اليدوي.

## إعداد GitHub
1. أنشئ مستودعاً جديداً باسم `AI-MATCH-PRO`.
2. ارفع جميع محتويات هذا المجلد إلى جذر المستودع.
3. تأكد من وجود مجلد `gradle/wrapper` وملفات `gradlew` و`gradlew.bat` عند الرفع من Android Studio أو مشروع Gradle wrapper كامل. إذا لم تكن موجودة، أنشئ Gradle Wrapper محلياً باستخدام `gradle wrapper`.
4. اربط المستودع بـ CodeMagic وشغّل workflow `android-debug`.

## API
- التسجيل: https://highlightly.net/
- التوثيق: https://highlightly.net/football-api/documentation/
- هذا المشروع يستعمل `https://soccer.highlightly.net/matches`.
- المفتاح يدخل من داخل التطبيق ولا يوضع في GitHub.

## تنبيه أمني مهم
إدخال المفتاح داخل التطبيق مناسب للاختبار الشخصي فقط؛ يمكن استخراج المفتاح من APK بواسطة شخص لديه خبرة. قبل نشر التطبيق للعامة، انقل الاتصال إلى backend خاص بك وضع المفتاح في متغير بيئة على الخادم.

## حدود البيانات
التغطية والمباريات المتاحة تعتمد على خطة حساب Highlightly. لا يعني وصف 950+ دوري أن كل مباراة متاحة في الخطة المجانية. واجهة API تعرض رسالة الخطة وبيانات التغطية.

## التوقعات
هذه النسخة لا تدّعي توقع نتائج مضمونة ولا تولّد توقعات وهمية. محرك التوقعات يحتاج إضافة بيانات تاريخية/إحصائية والتحقق من جودة التغطية قبل إظهاره للمستخدم.
